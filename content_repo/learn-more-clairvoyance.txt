THE DIFFERENCE BETWEEN CLAIRVOYANCE AND REMOTE VIEWING

Clairvoyance and remote viewing are closely related, but they are not exactly the same thing.
A useful way to distinguish the main ESP terms is this:
- Telepathy means perceiving information associated with another mind.
- Clairvoyance means perceiving a hidden, distant, or otherwise inaccessible target directly, without the ordinary senses.
- Remote viewing is usually understood as a more structured, disciplined, and testable form of target perception, often carried out under a blind protocol and followed by judging.
So clairvoyance is the broader category. Remote viewing is usually treated as a special method or application within that broader category.
If a picture is displayed on a monitor screen that you cannot see because it is covered, and no one is mentally “sending” it to you, the cleanest term for what you are trying to do is clairvoyance. More specifically, one might call it screened-target clairvoyance.
However, the same basic task can be made to resemble remote viewing more closely if it is carried out in a more formal way. The difference is not mainly where the target is located. The difference is the protocol.
In ordinary clairvoyance practice, a person may simply try to perceive what is hidden and then compare the result with the target. In remote-viewing-style work, there is usually more structure. The target is selected randomly. The viewer does not know what it is. Ideally, no one present knows what it is. The viewer records impressions carefully. Then the response is judged against the actual target and one or more decoys.
So the same hidden-screen task may be called clairvoyance in the broad sense, but it moves toward remote viewing when it is conducted in a blind, carefully structured, and judgeable way.
Why This Distinction Matters
The distinction matters because different forms of ESP call for somewhat different expectations.
In telepathy, the question is whether the Receiver is picking up information associated with another person’s attention or mind.
In clairvoyance, the question is whether the person can directly perceive a hidden target without depending on another person’s mind.
In remote viewing, the question is again whether hidden-target perception occurs, but now the task is arranged in a way that makes it easier to test fairly, preserve the response, and evaluate it afterward.
So remote viewing is not a completely different psi ability from clairvoyance. It is better understood as a more formal way of doing clairvoyant target perception.
What Clairvoyant Perception Usually Feels Like
As with telepathy, the impressions associated with clairvoyance or remote viewing are often subtle, vague, partial, and short-lived.
One should not expect a clear internal photograph of the target. More often, what appears is fragmentary visual information: bits of shape, color, texture, motion, contrast, or spatial arrangement. The information may come as fleeting impressions rather than as a stable image.
That is why it helps to quiet the mind, reduce internal chatter, and notice whatever surprising visual information appears spontaneously. The task is not to force meaning onto the experience, but to observe carefully and remember what was perceived.
A Simple Remote-Viewing-Style Protocol
A hidden-screen experiment begins to resemble remote viewing when it includes features such as these:
1. A target is selected randomly from a well-prepared pool of clearly different images.
2. The viewer does not know the target.
3. Ideally, no one present with the viewer knows the target either.
4. The viewer is given time to observe impressions without interruption.
5. The response is preserved exactly, for example in notes or sketches.
6. Afterward, the response is compared with the true target and one or more decoys.
7. A judge or judges evaluate which image best matches the recorded impressions.
8. Results are analyzed over repeated trials.
These features help reduce cueing, guessing, and wishful interpretation. They also make the experiment more scientifically meaningful.
How ESP GYM Fits In
In ESP GYM, the Clairvoyance / Remote Viewing tools can be used in more than one way.
If the target image is hidden from the user and the user simply tries to perceive it and then chooses between two images, this is best thought of as a form of clairvoyance practice.
If the user wants to make the session lean more toward remote viewing, the procedure can be made more formal.
For example, the user can leave the covered or remote image on the screen for a longer period of time and use a sketchbook to draw impressions. Instead of trying only for a quick recognition, the user can allow more time for subtle impressions to develop and be recorded.
After that, the user can continue the trial in the usual way and indicate which of the two images shown appears to best match the impressions.
Then, after one or more trials, the user can go to the Performance Reports Raw Data for those trials and show a judge or judges:
- the sketchbook impressions
- the actual target image
- the decoy image
The judge can then rate which of the two images better matches the sketch. This makes the procedure more like remote viewing because it introduces preserved free-response material and later judging.
Why Sketching Can Be Valuable
Sketching is important because ESP impressions are often difficult to put into words. A person may perceive a curve, a cluster, a contrast, a vertical form, or a texture without knowing what object it belongs to.
A sketch can preserve these partial impressions better than language alone. Later, a judge may see meaningful correspondences between the sketch and the target even when the viewer could not name the target consciously.
So sketching can make the process both more informative and more testable.
A Practical Conclusion
The most accurate way to think about this is:
- If you are trying to perceive a hidden image directly, that is fundamentally clairvoyance.
- If you arrange the task in a blind, structured, record-preserving, and judgeable way, it becomes remote-viewing-style clairvoyance, or simply a form of remote viewing in the broader modern sense.
So remote viewing and clairvoyance are not enemies or opposites. Remote viewing is best understood as a more formal and testable way of using clairvoyant perception.
In ESP GYM, the same basic tool can therefore serve both purposes. It can be used as simple clairvoyance practice, or it can be made more like remote viewing by allowing longer observation time, recording impressions carefully, and using later judging against target and decoy images.
